Design and Implementation of a Bidirectional Inverter with Reduced Component Count
IEEE LATAM Transactions manuscript ID: 10916
This repository is intended to provide the MATLAB scripts and numerical data needed to
reproduce selected plots reported in the paper.

Included scripts
SCRIPT/SIMULATION	RELATED FIGURE	DESCRIPTION
simulink_file.mdl	Fig.4 to Fig.7	Reproduce simulation results
figure_11c_efficiency.m	Fig. 11(c)	Loads the experimental output-power-efficiency data, plot inverter-mode efficiency versus output power.
fig12b.m	Fig. 12(b)	Loads bidirectional-mode output-power-efficiency data, plots the efficiency curve
Requirements
•	MATLAB R2022b or later is consistent with the MATLAB/Simulink version cited in the manuscript.
•	No additional toolbox is required for these two plotting scripts.
